## Product Hunt Description Template

### First Paragraph (Hook):
"Site Auditor Pro helps developers and designers ensure their websites meet quality and accessibility standards. Audit any website in seconds for CSS consistency, JavaScript quality, performance issues, and WCAG AA/AAA compliance."

### Key Features (Bullet Points):
- 🎯 **Instant Website Auditing** - Enter any URL and get comprehensive results
- 🌓 **Dual-Mode Accessibility Analysis** - Test light AND dark mode simultaneously
- 📊 **Detailed Scoring** - Overall, CSS, and JavaScript scores with breakdown
- 🎨 **CSS Variable Extractor** - Extract and customize color themes live
- 📋 **Actionable Recommendations** - Get specific guidance with difficulty ratings
- 📄 **Export Options** - PDF reports, JSON data, Tailwind config, Figma tokens
- 🔄 **Audit History** - Track improvements over time
- 💻 **Code Analyzer** - Paste CSS/JS directly for instant analysis

### Use Cases:
- Web developers ensuring code quality before deployment
- Accessibility specialists checking WCAG compliance
- Design teams extracting and customizing website themes
- Agencies auditing client websites for optimization opportunities

### Tech Stack:
Built with React Native (Expo), TypeScript, and deployed on Vercel. Open source and free to use.
